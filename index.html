    隔离向导：如何降低同机多号风险

    1. 主号 → 虚拟机（最推荐）

      一台 VM 只登一个企微账号。Hyper-V / VMware / VirtualBox 均可。详见仓库 docs/VM_GUIDE.md。

    2. 辅号 → 本机安全模式

      勾选「安全模式」→ 管理员运行 → 准备 WeComSlot 用户 → 用「辅号模板」分批启动。

    3. 测试号 → 普通多开

      用「测试模板」验证多开是否可用，不要把主号放在测试环境。

    4. 行为收敛

      保持分档间隔；避免短时间杀进程再秒开；不要用脚本做群发/加好友。

    本工具做环境与配置隔离，不会伪造设备指纹。服务端仍可能关联同物理机。
