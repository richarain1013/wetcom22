# 虚拟机一号一环境（推荐主号）

重要账号建议：**一台虚拟机只登录一个企业微信账号**。隔离强于「本机多开 / 安全模式」，也更接近正规运维做法。

本启动器负责本机多开；虚拟机方案由系统自带或第三方虚拟化完成。

---

## 方案对比

| 方案 | 隔离强度 | 适用 |
|------|----------|------|
| 普通多开 | 低 | 临时测试 |
| 安全模式（本地用户） | 中 | 辅号 / 日常 |
| **虚拟机一号一环境** | 高 | **主号 / 高价值账号** |

---

## 准备清单

1. 电脑内存建议 ≥ 16GB（每台 VM 分配 2–4GB）  
2. 磁盘预留充足空间（每台 Win10/11 约 20–40GB）  
3. 企业微信安装包（与宿主机版本尽量一致）  
4. 可选：不同账号使用不同网络出口（公司政策允许时）  

---

## 路线 A：Hyper-V（Windows 专业版/企业版）

1. **启用 Hyper-V**  
   - 控制面板 → 程序和功能 → 启用或关闭 Windows 功能 → 勾选 Hyper-V → 重启  
2. **新建虚拟机**  
   - 打开 Hyper-V 管理器 → 新建 → 虚拟机  
   - 内存：2048–4096 MB；网络：Default Switch 或外部交换机  
3. **安装 Windows**  
   - 挂载官方 ISO，完成安装与更新  
4. **安装企业微信**  
   - 仅登录 **一个** 工作账号  
5. **快照**  
   - 登录稳定后打检查点，方便回滚  
6. **一号一机**  
   - 第二个账号请再新建一台 VM，不要在同一 VM 里多开  

---

## 路线 B：VMware Workstation / VirtualBox

1. 安装 VMware 或 VirtualBox  
2. 新建虚拟机 → 分配 CPU/内存/磁盘  
3. 安装 Windows + 企业微信  
4. **每个账号克隆一台干净 VM**（完整克隆，不要共用同一磁盘）  
5. 主号 VM 可设置开机启动企微（可选）  

提示：克隆前先关机；克隆后在各 VM 内重新登录，避免会话冲突。

---

## 推荐拓扑（8–10 账号示例）

```
物理机
├── 主号 A  →  VM-1（仅此号）
├── 主号 B  →  VM-2（仅此号）
└── 辅号 1–6 → 本机「安全模式」WeComSlot1–6
    或测试号 → 本机普通多开
```

---

## 运维注意

- 虚拟机与宿主机 **不要共用** 企微数据目录  
- 大版本升级：先在一台测试 VM 验证，再推广  
- 出现异常登录提示：先停批量操作，检查是否同出口 IP 短时登录过多  
- 本工具 **不会**、也 **不应** 伪造设备指纹；虚拟机提供的是环境隔离，不是对抗风控  

---

## 与启动器的配合

1. 主号：按本文创建 VM，不依赖多开  
2. 辅号：本机启动器 → 勾选安全模式 → 分档选「辅号模板」  
3. 测试：启动器「测试模板」验证多开是否可用  

应用内也可打开「隔离向导」查看精简步骤。
